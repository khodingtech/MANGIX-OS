# MANGIX-OS
## Business Operating System

MANGIX-OS is a modern business operating system designed to centralize business operations, management, productivity, analytics and workflow automation.

### Core Modules

- Dashboard
- Business Management
- Finance
- Projects
- Employees
- Customers
- Inventory
- Analytics
- Documents
- Settings

### Design System

MANGIX-OS uses a clean glassmorphism interface built around the official MANGIX brand identity.
